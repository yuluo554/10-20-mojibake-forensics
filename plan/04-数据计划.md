### 1.1 目录布局

```text
data/
  README.md                     # 依据查证 + 数据源 + 数值口径（唯一权威）
  fixtures/
    attr/{gen.py,expect.json,README.md}
    explain/{gen.py,expect.json,README.md}
    recover/{kun-jin-kao,tang-tang,question-mark,replacement-char,silent-drop}/{gen.py,expect.json,README.md}

    scan/{gen.py,clean-corpus.json,polluted/,expect.json,README.md}
```

> fixture 文本文件一律用 `.json` / `.md`；`.gitignore` 排除 `*.txt`，如需入库的文本 fixture 必须用 `.json` 或显式 `!` 例外并在 `data/README.md` 登记。

## 二、真值纪律

1. **真值只存输入与期望**：`expect.json` 字段只允许 `input` / `expected` / `criteria` / `note`；出现 `observed_*` 即判红。
2. **期望可由输入独立复算**：测试里用标准库 `codecs` 重放期望链路，不复用被测实现的内部状态。
3. **生成器确定性**：禁 `random`、禁时钟、禁集合迭代序；重生成到临时目录与入仓件逐字节比对（`--check`）。
4. **五类不可逆各自有真值**：`recover` 的 `LOST` / `NOT_MOJIBAKE`、丢失点偏移、成因码都写进 `expect.json`。
5. **干净语料反例必须有**：`scan` 的干净基线必须断言 0 报告、0 改动；只测正例不算覆盖。
6. **不得用抽样结论代替全量判据**：fixture 的每一条期望都在 `--check` 里全量复算，不做抽样。
7. **跨解释器**：文本产物要求 3.8 与 3.12 重生成逐字节一致；zip 类 fixture 固定 `ZIP_STORED`、`create_system=0`、固定时间戳 `(1980,1,1,0,0,0)`。

## 四、数据来源与许可

| 来源 | 三态 | 许可 / 边界 |
|---|---|---|
| Python 标准库 `codecs` / `encodings` | ✅ 随解释器冻结 | Python Software Foundation License；不额外分发数据文件 |
| 公开中文文本（干净基线） | ✅ 本地取样 | **只提取统计，不入仓原文**；基线只登记"抽样来源类别 + 规模量级 + 期望命中 0" |
| 中文词频表 | ⬜ 未获取 | 默认关闭；只接受可再分发的词表，用户本地 `--freq` 加载；**任何第三方词表原文不入仓** |
| 真实用户乱码样本 | ⬜ 不采集 | 常含客户数据；fixture 全部合成 |
| V2EX / 知乎 / Reddit | ❌ 不可达 | 不引用、不编造链接（见 `data/README.md` 开头） |

## 五、fixture 验收门

| 门 | 判据 | 落地里程碑 |
|---|---|---|
| 可重建 | `python data/fixtures/<m>/gen.py --check` 重生成逐字节一致 | M1–M5 |
| 真值可复算 | 独立脚本按 `expect.json` 的链路重放，逐字节相等 | M1–M5 |
| 五类不可逆齐 | 五个目录各一例，`expect.json` 含 `status` + `loss` | M4 |
| 三类管道齐 | BOM 冲突 / UTF-16 奇偶 / zip 带与不带 `0x800` | M5 |
| 干净基线 | `new == []`、文件前后 sha256 不变 | M5 |
| 跨解释器 | 3.8 与 3.12 文本产物逐字节一致 | CI |
| 零真实数据 | 全文扫描无真实域名/邮箱/人名/机构 | M6 脱敏 |

## 六、干净语料基线的构造口径

- 来源类别：公开中文网页/文档的短句（自行编写或已改写的极小片段），**不保存原文**。
- 统计维度：字符类别分布（ASCII / CJK / 假名 / 谚文 / 控制符）、UTF-8 可解码性、行数级别。
- 基线 JSON 只含：文件相对路径、允许命中类别（默认空）、抽样来源类别、抽样规模量级。
- 构造脚本 `gen.py` 在仓库内可复现；**不依赖网络**，不下载语料。
- 误报防线：干净语料 `scan` 必须 0 报告；若某文件被报，先修检测阈值或把该形态登记为已知误报并在基线里显式豁免（豁免必须写理由）。
