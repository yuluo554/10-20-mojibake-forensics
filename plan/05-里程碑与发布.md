## 五、本机环境事实（实测 2026-10-20）

| 事实 | 命令 / 值 | 影响 |
|---|---|---|
| Python 通道 | `py -0p`：3.8.8-64、3.12-64 | 底线 3.8；CI 也测 3.12 |
| 默认 `python` | 商店占位符，不可用 | 一律 `py` / `py -X utf8` |
| pytest | 3.8 → 7.4.4；3.12 → 8.4.2 | 两通道都能跑全量测试 |
| Node | `node v24.15.0` | 布局门仍用 Python 实现，不依赖 Node |
| git | `2.54.0.windows.1` | 发布期用 `gh` + `git` 双通道 |
| 网络 | GitHub git 通道可能间歇阻断；`api.github.com` 通常可达 | M6 用 `gh api` 建仓/Release，push 重试 |
| 编码坑 | Git Bash 打印 UTF-8 中文可能显示乱码 | 验收文件用解析器/`py -3.12` 读取，不靠控制台肉眼 |

## 六、风险与预案

| 风险 | 概率 | 影响 | 预案 |
|---|---|---|---|
| 候选集在链深 3 爆炸 | 中 | 性能/可读性 | 链深上限 3；超限报 `depth_limit_reached`；`--top` 只影响展示 |
| 打分排序不稳 | 中 | 双跑不一致 | 排序键固定；浮点定点化；双跑测试 |
| `U+FFFD` 误判为可恢复 | 中 | 自信的错误答案 | 不可逆五类先判死；`verify` 失败降级 |
| 干净语料误报 | 中 | `scan` 不可用 | 零报告基线 + 误报豁免需理由 |
| 跨平台 zip/文本字节漂移 | 低 | `--check` 在 CI 红 | `ZIP_STORED` + 固定时间戳 + 固定 `create_system`；`-text` 标记字节冻结件 |
| 发布期 GitHub 通道不稳 | 中 | 发布延迟 | `gh api` 建 tag/Release；push 重试；远端 sha 对账 |
| 文档与代码口径漂移 | 中 | 结论不可信 | 口径单点 `data/README.md` §四；布局门 + 文档点名工具存在性检查 |
