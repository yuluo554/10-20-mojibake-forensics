### 1.1 招牌动词 → 命令 → 断言

| 能力名词 | 交付态命令 | 断言 |
|---|---|---|
| 有界候选集 | `forensics attr --text <s>` | `bench/run.py` 57 例：真答案在候选集内 100% |
| 置信度区间 | `attr` 的 `candidates[*].confidence` | 分项分与排序键固定性测试；双跑一致 |
| 链深偏好 | `attr` 的 `score.depth` | 浅层/深层候选对照用例 |
| 字节证明 | `forensics explain --text <s> --pick 1` | 独立重放脚本全绿；改错 codec → 具体 step |
| 多解对照 | `explain --vs 2` | 分叉点字节逐字节断言 |
| 不可逆判死 | `forensics recover ...` | 五类各一条单测；无自造字符 |
| BOM / 奇偶错位诊断 | `forensics file --path <f>` | 三类管道 fixture golden |
| zip 文件名归因 | `file --path <f.zip>` | 带/不带 `0x800` 两个 fixture |
| 零误改基线 | `scan --baseline clean.json --format json` | 干净语料 0 报告；污染语料非 0 |
