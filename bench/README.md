# bench · 57 例探针

> 状态：**骨架（M0）**。`run.py` 只冻结探针形状，返回退出码 4；M1/M2 实装生成与复算。

## 口径

- 10 个编码器 × 6 个解码器、链深 2、10 个中/日/韩合成样本 × 8 个事故场景 = **57 例**。
- 探针数字是**小样本自测的方法可行性证据，不是产品指标**。
- 唯一允许的硬门：真答案落在候选集内 **100%**（判据正确性验证，不是性能指标）。
- 链深 3 的候选规模与排序效果 **⬜ 未实测**，不得外推。

## 输出

- `bench/out/attr.json`：候选规模分布、真答案是否入集、排序位置等。
- `bench/out/` 不入仓（`.gitignore`）。

## 命令

```bash
python bench/run.py
python bench/run.py --check     # M2 起：重算并与冻结输出比对
```

数值口径唯一来源：`data/README.md` §四。
