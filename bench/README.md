# bench · 57 例探针

> 状态：**M1 落地；M2 追加 `depth3` 块**。`run.py` 程序化生成 57 例并复算；`bench/golden/attr.json` 是冻结的可复算记录，`--check` 逐字节比对；`bench/out/` 不入仓。

## 口径

- 10 个编码器 × **7 个解码器**（以 `src/mojibake_forensics/codecs_table.py` 的冻结集合为准；出题期一次性脚本描述写"6 个"，与冻结集合不一致，M1 按代码更正）。
- 链深 2（decode 步数）；10 个中/日/韩合成样本 × 8 个事故场景 = 80 组合，其中 **57 例可用**（严格编解码失败、文本无变化、真值链不可验证的 23 例不计）。
- 探针数字是**小样本自测的方法可行性证据，不是产品指标**。
- 唯一允许的硬门：真答案落在候选集内 **100%**（判据正确性验证，不是性能指标）。
- **`depth3` 块（M2）**：调用真实 `attr` 在冻结上限 `MAX_DEPTH=3` 重跑同 57 例，记录完整候选/链路规模与真答案名次；`--top` 不参与，计数始终完整。

## 输出

- `bench/golden/attr.json`：入仓冻结件，含探针矩阵、逐例真值链与 minimal 候选、汇总指标、`depth3` 块（M2）。
- `bench/out/attr.json`：默认产物，`.gitignore` 排除。
- 输出不含时间、主机名、绝对路径、Python 版本，便于跨解释器逐字节比对。

## 命令

```bash
python bench/run.py                 # 生成 bench/out/attr.json
python bench/run.py --check         # 重算并与 bench/golden/attr.json 比对
python bench/run.py --freeze        # 重新冻结 golden（仅口径变更时使用）
```

退出码：`0` 成功 / `1` golden 不一致或矩阵漂移 / `3` codec 不可用。

数值口径唯一来源：`data/README.md` §四；探针复跑记录：§1.3.1。
